## 🚀 Featured Project

### Microservices-Based E-Commerce Platform

**Tech Stack:**  
Java, Spring Boot, MySQL, Kafka, Redis, Docker, JWT, API Gateway, Eureka

**Overview:**  
A production-style **e-commerce backend system** built using **microservices architecture**, focusing on scalability, security, and fault isolation.

**Key Capabilities:**
- Authentication & authorization using JWT and OTP
- User and admin role management
- Inventory and stock reservation
- Order lifecycle management
- Payment integration
- Event-driven notifications
- API Gateway with rate limiting
- Service discovery with Eureka
